# Copywrk Portfolio V6

A multi-page Next.js portfolio for Copywrk with GSAP scroll choreography and Lenis smooth scrolling.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```bash
npm run build
npm start
```

Vercel can deploy this repository directly.

## Motion system

- Lenis smooth scrolling
- GSAP ScrollTrigger reveals and parallax
- Opening page curtain
- Hero line-by-line intro
- Scroll progress indicator
- Custom desktop cursor
- Image parallax on project cards and case studies
- Animated manifesto word reveals
- Infinite services marquee
- Staggered process steps
- Reduced-motion accessibility fallback

Project content lives in `data/projects.ts`.
